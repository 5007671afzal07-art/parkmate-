Hardware Integration Architecture Disclaimer

Notice: This web application runs in Simulation Mode. It does not falsely claim active physical camera AI or embedded ultrasonic hardware. The codebase uses an enterprise-grade Hardware Gateway Interface (in js/hardware-sim.js) configured with modular adapter hooks. In production, real IP cameras with RTSP/ONVIF streams, LoRaWAN/MQTT slot sensors, and Wiegand relay controllers bind directly to these identical software event channels.
